# Personal human review checklist — not automatically confirmed

The responsible human must personally read and understand the exact runtime fingerprint in [SOURCE-REGISTER.md](SOURCE-REGISTER.md). This is an uncompleted template, not a review certificate.

1. `main`, `app`, `interaction`: events, Start/Stop, focus, shutdown, own gestures and failure states.
2. `action_click`, `keybinds`, `action_bars`, `native_bars`, `bar_settings`, `locator`: input attempts versus execution, native boundaries, slot identities, corrections, recast stages and duplicate events.
3. `model`, `storage`, `util`: limits, read-only migration, backup and non-atomic conflict protection.
4. `catalogue`, `equipment`, `item_identity`, `spells`, `prayers`, `data`: current membership, positive identity, exclusions, legacy references, exact-one reminder identities and updates.
5. `ui`: documented component contracts, callback scopes retired before Destroy, search, drag/resize/slider, click-through and Hub integration.
6. `diagnostics`, `i18n`: bounded local output and stable identities across languages.
7. Compare user documentation and regressions with actual behaviour.
